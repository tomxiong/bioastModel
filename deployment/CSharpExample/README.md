# EfficientNetV2-S BioAST分类器 C# 示例

这是一个完整的C#控制台应用程序，演示如何使用EfficientNetV2-S ONNX模型进行生物抗菌素敏感性测试图像分类。

## 功能特性

- ✅ 单张图像预测
- ✅ 批量图像预测
- ✅ 异步批量处理
- ✅ 性能测试和基准测试
- ✅ 详细的预测结果和统计信息
- ✅ 医学建议提示
- ✅ 错误处理和资源管理

## 环境要求

- .NET 6.0 或更高版本
- Windows/Linux/macOS

## 快速开始

### 1. 准备模型文件

将 `efficientnet_v2_s.onnx` 模型文件复制到项目根目录中。

### 2. 安装依赖

```bash
dotnet restore
```

### 3. 编译项目

```bash
dotnet build
```

### 4. 运行程序

```bash
dotnet run
```

## 图像预处理

程序会自动对输入图像进行以下预处理：

1. **尺寸调整**: 调整为70×70像素
2. **像素值归一化**: [0,255] → [0,1]
3. **ImageNet标准化**: 
   - 均值: [0.485, 0.456, 0.406]
   - 标准差: [0.229, 0.224, 0.225]
4. **通道排列**: RGB格式，维度为[1, 3, 70, 70]

## 预测结果解释

### 类别说明
- **Benign**: 阴性结果，表示样本正常
- **Malignant**: 阳性结果，表示样本异常

### 置信度指导
- **高置信度 (>90%)**: 结果可靠
- **中等置信度 (70%-90%)**: 结果较可靠，建议复核
- **低置信度 (<70%)**: 建议人工复核

### 医学建议
程序会根据预测结果和置信度提供相应的医学建议：

- 🔴 **高置信度阳性**: 建议进一步检查
- 🟢 **高置信度阴性**: 结果正常
- 🟡 **低置信度**: 建议人工复核

## 性能优化

### GPU加速（可选）

如果系统支持CUDA，可以修改 `BioASTClassifier.cs` 中的构造函数来启用GPU加速：

```csharp
var options = new SessionOptions();
options.AppendExecutionProvider_CUDA(0); // GPU设备ID
_session = new InferenceSession(modelPath, options);
```

### 内存优化

对于大批量处理，考虑：
- 分批处理图像
- 及时释放图像资源
- 重用张量对象

## 常见问题

### Q: 程序提示"模型文件不存在"？
A: 请确保 `efficientnet_v2_s.onnx` 文件在程序目录中。

### Q: 预测结果不准确？
A: 检查输入图像是否符合训练数据的特征，确保图像质量良好。

### Q: 程序运行缓慢？
A: 考虑启用GPU加速或使用异步批量处理。

### Q: 内存占用过高？
A: 对于大批量处理，建议分批处理或增加系统内存。
