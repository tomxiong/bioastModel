## 🎯 方案设计

### 为什么选择Ensemble？

**v1.2和v1.2.1的失败教训**:
1. Medium模型: 性价比低，提升微弱
2. 任务权重调整: 破坏平衡，适得其反

**Ensemble的优势**:
1. ✅ **无需修改模型架构** - 使用已验证的v1.1配置
2. ✅ **降低随机性影响** - 多个模型投票，更稳定
3. ✅ **提升泛化能力** - 不同随机种子捕获不同模式
4. ✅ **预期收益明确** - 学术界验证的0.5-1.5%提升

### 2. Ensemble配置

**训练3个模型**:
- **Model 1**: seed=42 (v1.1原始种子)
- **Model 2**: seed=123
- **Model 3**: seed=2024

**为什么选择3个模型？**
- 2个模型: 投票可能平局
- 3个模型: 可以多数投票，平衡成本和收益
- 5个模型: 收益边际递减，成本过高

### 3. 集成方法

**软投票 (Soft Voting)**:
```python
# 对每个任务分别进行概率平均
def ensemble_predict(models, input_data):
    predictions = []
    for model in models:
        pred = model.predict(input_data)
        predictions.append(pred)

    # 对三个任务分别平均
    ensemble_pred = {
        'growth_level': torch.mean(torch.stack([p['growth_level'] for p in predictions]), dim=0),
        'growth_pattern': torch.mean(torch.stack([p['growth_pattern'] for p in predictions]), dim=0),
        'interference_factors': torch.mean(torch.stack([p['interference_factors'] for p in predictions]), dim=0)
    }

    return ensemble_pred
```

**为什么选择软投票而非硬投票？**
- 软投票: 利用概率信息，更准确
- 硬投票: 仅使用最终类别，信息损失
